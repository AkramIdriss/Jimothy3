# User Stories

## Example User

I wanted a based box, so I selected that style, entered 200mm for the length, 200mm for the width, 200mm for the height, and 22mm for the tooth width. I also entered the monogram "BX." I then downloaded the SVG and laser cut it in the Maker Lab.

## Example User 2

I wanted somewhere to keep my index cards while studying, so I selected the note holder style and chose the index card size. I entered "Reeves" as the engraving, checked the preview to make sure it fit on the bottom panel, and downloaded the SVG to cut in the Maker Lab.

## Example User 3

I wanted a box with a drawer to hold my jewelry, so I selected the sliding box style and entered 150mm for the width, 80mm for the height, 120mm for the depth, and 10mm for the tooth width. I also entered the monogram "SR." The terminal showed me the size of the inner drawer, so I knew it would fit inside the outer box. I then took the SVG to the Maker Lab, cut it out of 3mm wood, and glued the outer box and drawer together.

## Example User 4

I wanted a crate to store my vegetables, so I selected the crate style and entered 300mm for the length, 200mm for the width, 200mm for the height, and 15mm for the tooth width. I wanted air to flow through it, so I chose circles for the holes on the sides. I checked the labels on the SVG to see where each panel goes, then laser cut it in the Maker Lab and taped it together.
