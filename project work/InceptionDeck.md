# Inception Deck

## Why are We Here?

We are here to make SVG files of boxes to cut out on a laser printer.


## Elevator Pitch

This is a project that was inherited to us, so that we may use the previous year's work, and improve upon their SVG file-making prgrams, and make better boxes.


## Product Box

It's free! Make boxes to your heart's content.


## NOT List

This is not:
- a program with a UI (or it won't be).
- something that isn't a Java program from which you can make a SVG file of a box.
    - The SVG will make a physical box, however. 


## Meet the Neighbors
