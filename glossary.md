# Glossary for Laser Box Project
Kerf - what is cut off when the laser does what a laser does, laser things; the thickness of a laser beam
Kerf Compensation - Offsetting a laser path to account for kerf
Laser Cutting (Vector Cutting) - cutting all the way through the wood
Raster - digital file type used to engrave items
Scoring (Laser Vestor Scoring) - marking the wood, but not cutting all the way through it
SVG - the file type accepted by the laser cutter for use
Vector - file that tells the laser where to cut; SVG file
# This is subject to change, the known terms are incomplete.
